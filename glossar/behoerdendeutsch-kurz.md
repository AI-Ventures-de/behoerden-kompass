# Behörden-Deutsch → einfach (Kurz-Glossar)

| Begriff | Heißt einfach |
|---|---|
| Widerspruch | „Ich bin nicht einverstanden“ — schriftlich, mit Frist (meist 1 Monat ab Briefdatum) |
| Einspruch | Wie Widerspruch, aber bei Finanzamt/Steuer |
| Frist | Letzter Tag, an dem dein Brief ankommen muss (nicht abgeschickt sein muss!) |
| Bescheid | Amtliche Entscheidung auf Papier — kann man anfechten |
| Bestandskräftig | Zu spät zum Widerspruch — gilt jetzt |
| EKS | Einkommens- und Vermögensbescheinigung (Jobcenter will wissen, was du hattest) |
| Sanktion | Geld-Kürzung, wenn du Pflichten nicht erfüllst |
| Ermessen | Das Amt DARF entscheiden — gut begründen hilft |
| Pfändung | Gläubiger holt sich Geld direkt vom Konto/Lohn |
| P-Konto | Geschütztes Konto — Grundfreibetrag kann nicht gepfändet werden |
| Titel | Vollstreckbare Urkunde — damit kann gepfändet werden |
| Verjährung | Forderung wird nach Zeit wertlos (meist 3 Jahre, tituliert 30 Jahre) |
| Restschuldbefreiung | Gericht sagt: alle Schulden sind nach 3 Jahren Wohlverhalten erlassen |
| Wohlverhaltensperiode | Die 3 Jahre, in denen du dich schuldenfrei verhalten musst |
| Beistandschaft | Jugendamt treibt Unterhalt fürs Kind ein (kostenlos für die Mutter) |
| Unterhaltsvorschuss | Staat zahlt vor, wenn der Vater nicht zahlt — holt es sich dann von ihm zurück |
| Kostenzusage | Jobcenter verspricht, die Kosten (z.B. Schuldnerberatung) zu übernehmen |
| Verfahrenskostenstundung | Staat übernimmt die Gerichtskosten der Insolvenz (bei wenig Einkommen) |
| Außergerichtlicher Einigungsversuch | Erst alle Gläubiger fragen, ob sie einen Vergleich annehmen, DANN Gericht |
