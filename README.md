# 🧭 Behörden-Kompass

**Behördenkram verständlich — für Gehirne, die anders ticken.**

Briefe von Ämtern, Formulare, Fristen, Verfahren: Für Menschen mit ADHS ist das oft eine Wand aus Text, in der nach zwei Sätzen nichts mehr ankommt. Dieser Kompass übersetzt Behörden-Deutsch in klare Sprache, zerlegt Verfahren in kleine Schritte und liefert fertige Vorlagen.

> ⚠️ **Kein Rechtsrat.** Dieses Projekt teilt Erfahrungswissen und allgemeine Erklärungen — keine individuelle Rechtsberatung. Im Zweifel: Schuldnerberatung, Sozialberatung oder Anwalt fragen (viele Beratungen sind kostenlos).

## 📂 Was hier drin ist

| Ordner | Inhalt |
|---|---|
| `anleitungen/` | Verfahren Schritt für Schritt: Was passiert, in welcher Reihenfolge, mit wem du sprichst |
| `vorlagen/` | Briefe & Formulare zum Anpassen: Widerspruch, Antrag, Nachfrage, Ratenzahlung |
| `glossar/` | Behörden-Deutsch → einfach: Paragraphen, Begriffe, Abkürzungen übersetzt |
| `checklisten/` | Was mitnehmen, was vorbereiten, was NICHT tun — kompakt für Termine |

## 🧠 Die 5 Kompass-Prinzipien

1. **Eine Sache pro Seite** — kein Textwust, kurze Abschnitte
2. **Schritt = eine Aktion** — niemals "dann prüfen Sie ggf. die Voraussetzungen"
3. **Fristen immer als Datum** — nicht "2 Wochen", sondern "bis 24.09.2026"
4. **Jede Antwort ist ein Skript** — "Sag genau das: …"
5. **Du musst nichts verstehen, nur ausführen** — Erklären ist Bonus, nicht Pflicht

## 🚀 Erste Schritte für dich

- Kein Plan? Starte bei `anleitungen/` — wähle dein Thema (Jobcenter, Schulden, Unterhalt, Widerspruch)
- Ein Brief liegt auf dem Tisch? Schau ins `glossar/` oder such eine Vorlage in `vorlagen/`
- Termin beim Amt? Öffne die passende `checklisten/`-Datei

## 🤝 Mitmachen

Erfahrung teilen? Eigene Vorlage, die funktioniert hat? Pull Request oder Issue — jede echte Erfahrung hilft.
